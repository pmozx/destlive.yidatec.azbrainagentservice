## 二、交付范围

### 2.1 接口清单（20 个，全部挂在独立 `/v1` 前缀下）

| # | 方法 | 路径 | 说明 | 关键契约约束 |
| --- | --- | --- | --- | --- |
| 01 | POST | `/v1/parse/jobs` | 提交文档 / FAQ 解析任务 | 202 受理；`job_id` 幂等；10MB 请求体上限 |
| 02 | GET | `/v1/parse/jobs/{job_id}` | 查询解析进度与完整结果 | 四态状态机；`failed` 走 HTTP 200 + `error_code`；`chunks` 不得含向量 |
| 03 | POST | `/v1/knowledge/entries` | 首次发布写入正式切片 | 已有 `publication_id` 返回 409，不得隐式覆盖；`revision` 从 1 起 |
| 04 | POST | `/v1/knowledge/entries/{publication_id}/query` | 读取当前生效基线 | 修订前的基线快照，供 `base_record_id` 冲突校验 |
| 05 | PUT | `/v1/knowledge/entries/{publication_id}` | 修订（版本切换 / 单片删除） | 基线不一致 409；`revision` 单调递增；原子版本切换 |
| 06 | DELETE | `/v1/knowledge/entries/{publication_id}` | 整单删除 | 删除后切片不可召回；保留幂等墓碑（同 ID 重放返回原回执） |
| 07 | POST | `/v1/knowledge/search` | 关键词 / 自然语言检索 | 实时授权范围内检索（7 张共享表下推）；禁止先全库后过滤 |
| 08 | POST | `/v1/chat/sessions` | 创建新会话 | 会话归属 `tenant_id + user_id` |
| 09 | POST | `/v1/chat/sessions/query` | 分页查询我的会话 | 游标分页；POST 承载签名身份 |
| 10 | POST | `/v1/chat/sessions/{session_id}/query` | 会话详情（含历史分页） | 历史消息、引用；知识依赖失效整条隐藏 |
| 11 | PATCH | `/v1/chat/sessions/{session_id}` | 修改会话标题 | 归属校验；非本人 403 |
| 12 | DELETE | `/v1/chat/sessions/{session_id}` | 删除会话 | **DELETE 携带 JSON 正文，网关须透传** |
| 13 | DELETE | `/v1/chat/sessions/{session_id}/messages` | 清空会话历史 | 保留会话壳；迟到生成结果不得写回 |
| 14 | POST | `/v1/chat/completions` | 发送问题并生成回答 | **非流式**（`stream=true` 返回 `UNSUPPORTED_STREAM`）；60s 超时 |
| 15 | POST | `/v1/chat/requests/{target_request_id}/query` | 查询超时操作的结果 | 正文 `request_id` 为新 ID，路径为原操作 ID；覆盖 completion / mutation / delete |
| 16 | POST | `/v1/knowledge/duplicates/check` | 保存前重复检查 | 按 `scope`（候选资源清单）检测，返回相似度与命中依据 |
| 17 | POST | `/v1/knowledge/duplicates/groups/query` | 查询重复分组 | 分组列表与组内成员数 |
| 18 | POST | `/v1/knowledge/duplicates/groups/{group_id}/query` | 分组详情与对比依据 | 组内条目、标题/摘要/切片重叠对比 |
| 19 | POST | `/v1/knowledge/duplicates/merge-preview` | 合并预览 | 草稿态**不落正式库**；正式变更仍走 #03/#05 |
| 20 | POST | `/v1/knowledge/entries/{publication_id}/deactivate` | 停用已生效知识 | 停用后不参与检索；审批语义由 GSI 把关 |

> 20 个接口对应 18 个唯一路径：`entries/{publication_id}`（#05 PUT / #06 DELETE）与 `chat/sessions/{session_id}`（#11 PATCH / #12 DELETE）各承载两个方法。

### 2.2 跨切面能力（不体现为独立接口，但必须交付）

| 编号 | 能力 | 要点 |
| --- | --- | --- |
| C1 | HMAC 四头签名鉴权 | `X-AI-Client / X-AI-Timestamp / X-AI-Nonce / X-AI-Signature`；`authorization{scope_id, issued_at, expires_at≤120s}`；±5 分钟窗口；不排序不重序列化 |
| C2 | 防重放 | `client_id + nonce` 原子登记（`sbp_ai_system_nonce`），保留至 timestamp + 5 分钟 |
| C3 | 幂等台账 | `job_id` / `event_id` / `request_id` 三类（`sbp_ai_system_idempotency` + `request_log`）；同 ID 不同正文 → 409 |
| C4 | 统一错误体 | `{error:{code,message,retryable}}`；覆盖 400/401/403/404/409/413/429/503/5xx 分支 |
| C5 | 实时权限计算与 SQL 下推 | 只读查询 7 张 GSI 共享表（`sbp_sys_org`、`sbp_sys_org_member`、`sbp_sys_audience_team`、`sbp_sys_audience_team_member`、`sbp_sys_user`、`sbp_km_doc_publication`、`sbp_km_doc_record`）；SQL 下推过滤，禁止降级全库检索；共享表不可用时 503 `AUTHORIZATION_UNAVAILABLE`（ADR-8） |
| C6 | **对接接口统一审计** | 20 个 `/v1` 接口全部纳入 `sbp_ai_system_api_log`（ADR-13 / FR-AUD）：扩展 `auth_mode` / `client_id` / `request_id` / `security_check(JSONB)` 四列；被拒请求同样留痕；签名只存摘要、nonce 全量留存 |
| C7 | 共库治理 | 与 GSI 共用 `service_brain` 库 **public schema**；AI 表 `sbp_ai_[模块名]_[业务名]` 前缀隔离（23 张）；Alembic（AI）与 Flyway（GSI）分治 + CI 互检（ADR-10） |

### 2.3 明确不在本次范围

- **契约复核闭环**——接口复核暂缓（POC 先行），遗留疑点在 POC/联调期与 GSI 对齐，不作为开发前置阻塞（`00-1` 暂缓留档）；
- **语音质检全部内容**（转写解析、四类判定、质检编排、报告与 Findings）——接口文档未提供，暂缓（§十一）；
- 点赞 / 点踩、答案反馈（GSI 侧实现，AI 只需保持 `session_id` / `message_id` 稳定）；
- 权限计算本身（visibility / 部门 / 指定人由 GSI 维护，AI 只读共享表做检索期下推）；
- 知识业务状态与审批发布（GSI 维护，AI 只收「批准后的正式切片集合」）；
- 座席前端页面、知识中心管理页面；
- 种子文档收集与入库运营、培训与录屏、UAT 组织（运营/验收工作，不计入开发工时）。

## 六、单人产能与工期测算

```
容量 = 17 个自然周 × 5 工作日 − 元旦 1 天 − 春节 6 天（02-05 除夕、02-08~02-12；02-15 复工）= 78 人日
负载 = 63.5 人日（任务级汇总，36 个任务 = POC 验证 6.0 + 正式开发 57.5）
占用 = 81.4%，缓冲 = 14.5 人日（其中约 8.5 人日为任务排布半天空隙、6 个整日空档，净缓冲约 6 人日）
```

- 按约 4.0 人日/工作周有效产出（16 个工作周计，预留约 19% 管理事务）→ 63.5 / 4.0 ≈ **16 个工作周（17 个自然周，W15 为春节假期周）**，与排期一致；
- 若按 5 人日/周满负荷 → 约 13 个工作周，但无缓冲，不建议；
- 若必须压缩到 10 周量级（50 人日）：裁剪上限约 7 人日（§九）仍不足，只能砍整块范围，**20 接口无法全量交付**。
