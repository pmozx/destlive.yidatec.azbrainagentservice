## 一、本文件说明什么

本文只回答三个问题：

1. **这一期到底交付什么**——13 个接口 + 6 类跨切面能力，不含前端页面；
2. **怎么排、谁来做**——单人串行，12 周 / 59 个工作日 / 36 个任务 / 52.0 人日，M1–M7 七个门禁；
3. **风险与裁剪怎么控**——R1–R9 登记册、6 人日裁剪上限、每周五的偏差检查。

工时为什么不是 6 周、为什么不是 4 人并行、原 04/05 文档差在哪，见 `01-接口交付范围与工时评估.md`，本文不再重复。

## 二、交付范围

### 2.1 接口（13 个，全部挂在独立 `/v1` 前缀下）

| # | 方法 | 路径 | 说明 |
| --- | --- | --- | --- |
| 1 | POST | `/v1/parse/jobs` | 提交文档 / FAQ 解析任务 |
| 2 | GET | `/v1/parse/jobs/{job_id}` | 查询解析进度与完整结果 |
| 3 | POST | `/v1/knowledge/index` | 提交 / 停用 / 删除正式切片 |
| 4 | POST | `/v1/knowledge/search` | 关键词 / 自然语言检索 |
| 5 | POST | `/v1/chat/sessions` | 创建新会话 |
| 6 | POST | `/v1/chat/sessions/query` | 分页查询我的会话 |
| 7 | POST | `/v1/chat/sessions/{id}/query` | 查询会话详情与版本 |
| 8 | PATCH | `/v1/chat/sessions/{id}` | 修改会话标题 |
| 9 | DELETE | `/v1/chat/sessions/{id}` | 删除会话 |
| 10 | POST | `/v1/chat/sessions/{id}/messages/query` | 查询历史消息 |
| 11 | DELETE | `/v1/chat/sessions/{id}/messages` | 清空会话历史 |
| 12 | POST | `/v1/chat/completions` | 发送问题并生成回答（非流式） |
| 13 | POST | `/v1/chat/requests/{target_request_id}/query` | 查询超时操作的结果 |

### 2.2 跨切面能力（不单列接口，但必须交付）

| 编号 | 能力 | 落在 |
| --- | --- | --- |
| C1 | HMAC 五头签名鉴权 + nonce 防重放（±5 分钟窗口） | T1.1 |
| C2 | 统一错误体 `{error:{code,message,retryable}}` + 14 类错误码 | T1.2 |
| C3 | 三类幂等台账（`job_id` / `event_id` / `request_id`），同 ID 异正文返回 409 | T1.3 |
| C4 | `ai_knowledge` 独立 schema + 最小授权账号 + Alembic 迁移基线 | T1.4 |
| C5 | 白名单 `allowed_snapshots` SQL 下推与越权 0 命中 | T4.3 |
| C6 | 会话托管（`session_version` 乐观锁、归属校验、迟到结果丢弃） | T5.1–T5.7 |

### 2.3 明确不包含

前端页面（知识中心 UI）、点赞点踩、权限计算、种子文档入库、UAT 组织与培训、通话录音解析与质检（属二期 `03-1`/`03-2`）。若追加前端，需在本计划外增加 12–15 人日。

## 十一、工程约定

| 项 | 约定 |
| --- | --- |
| 路由 | 对外统一 `/v1/*`，独立 router，**不挂 JWT Bearer 依赖、不进审计路由**；基座 `/api/v1/*` 仅内部使用 |
| 鉴权 | 全部走 HMAC 五头；`client_id` 只认 `gsi-service`；密钥由环境变量注入，不入库不入仓 |
| 签名原文 | 原始路径 + 可选查询串，`body` 取原始字节 SHA-256；**禁止中间件重排 JSON 或改写路径** |
| 错误体 | 一律 `{error:{code,message,retryable}}`，不使用基座 `{code,msg,data}` 外层 |
| 数据 | 业务表落 `ai_knowledge` schema；GSI 不直连 AI 表；账号按 schema 最小授权 |
| 迁移 | 只走 Alembic；版本与发布单元变更需附回退说明 |
| 测试 | pytest；必测：签名、幂等、版本冲突、白名单越权、会话版本、超时结果 |
| 日志 | 请求日志记录 `request_id`/`session_id`/耗时，不落正文与密钥；与 GSI 对账用 |
| 幂等 | 重试不改变正文；`request_id` 相同而正文不同必须 409 |
| 配置 | `backend/env/.env.<env>` 唯一来源；新增项同步 README |

## 十二、风险（R1–R9）与裁剪顺序

| 编号 | 风险 | 影响 | 概率 | 应对 |
| --- | --- | --- | --- | --- |
| R1 | 单人单点，无并行、无评审、无替补 | 病假或联调等待直接延期 | 高 | 任务颗粒度 ≤3 人日；每周留缓冲；自审清单 + 契约用例先行 |
| R2 | `model_key` 清单未定 | 解析/生成接口无法定稿 | 高 | W1 冻结 default + 1 个解析专用 key，其余按参数校验拒绝 |
| R3 | 索引请求同步耗时可能超 60 秒 | 与 GSI 超时契约冲突 | 中 | W1 约定切片上限；必要时分批提交或协商异步补偿 |
| R4 | 非流式整答超 60 秒 | 体验与重试语义混乱 | 中 | 请求台账 + 结果查询必做；明确同 `request_id` 重试 |
| R5 | `pages` 页图渲染能力缺失 | 返回空数组可能不满足业务 | 中 | W1 确认可接受空页图，否则 +2 人日引入渲染依赖 |
| R6 | 白名单过大 `SCOPE_TOO_LARGE` | 检索不可用 | 中 | 临时表 JOIN 下推 + 上限校验，与 GSI 约定分批 |
| R7 | 路径前缀与鉴权体系冲突 | 签名原文路径不符导致 401 | 高 | 独立 `/v1` router，不挂 Bearer 与审计，禁止反代改写路径 |
| R8 | DELETE 携带 JSON 正文 | 网关丢弃 body | 中 | 上线检查单显式验证；必要时改 POST 需契约变更 |
| R9 | 旧计划口径未更新 | 对外承诺 6 周不可达 | 高 | 以 `02-1`/`02-2` 为交付口径，替换 4 人 6 周基线 |

**裁剪顺序（上限约 6 人日，超出须增派人力或延长工期）**

| 顺序 | 裁剪项 | 省人日 | 代价 |
| --- | --- | --- | --- |
| 1 | keyword 检索模式 | 1.0 | 需 GSI 确认不使用关键词搜索 |
| 2 | 会话改名 / 删除（#8 / #9） | 1.5 | 座席无法管理标题与删除会话 |
| 3 | 超时结果查询（#13） | 1.5 | 超时只能重问，重复计费 |
| 4 | `pages` 页图 | 1.0 | 解析结果无页面预览 |
| 5 | rerank 精排 | 1.0 | 召回精度下降，需接受评测结果 |

裁剪按上表顺序执行，先从末位可接受损失项开始，不允许跳序砍核心链路（T2/T3/T4.2/T5.5 不参与裁剪）。

## 十三、计划控制

1. **周检查**：每周五核对「计划人日 vs 实际」，偏差 > 1 人日即触发裁剪（按 §十二 顺序）；
2. **门禁**：M1–M5 未通过不进下一阶段；M6 未通过不进验收；
3. **变更**：接口契约由 GSI 变更时，先评估人日影响再承诺日期，禁止口头接受范围扩张；
4. **累计偏差 > 3 人日**时须向项目负责人书面报备，并给出「裁剪 / 加班 / 延期」三选一方案；
5. **跨期约束**：本计划结束（2027-01-22）后紧接着二期质检（W13 起），一期延期将整段顺延二期，不做压缩二期补偿。
