## 三、两期口径对照

| 项 | 一期 知识平台 | 二期 语音质检 | 合计 |

| 周期 | 2026-11-02 ~ 2027-01-22 | 2027-01-25 ~ 2027-04-02 | 2026-11-02 ~ 2027-04-02 |
| 周数 / 工作日 | 12 周 / 59 天 | 10 周 / 50 天 | 22 周 / 109 天 |

## 四、甘特表要点

- 时间轴拆两份：`02-2` 为 59 个工作日（2026-11-02 ~ 2027-01-22，元旦 2027-01-01 不计），`03-2` 为 50 个工作日（2027-01-25 ~ 2027-04-02）；
- **单人串行**：任一工作日只被一个任务条占用，两份表的生成脚本各自内置断言校验；任务不跨自然周；
- 里程碑以 `◆` 标在对应日期列：一期 M1 11-13 / M2 11-23 / M3 12-04 / M4 12-11 / M5 12-31 / M6 01-08 / M7 01-22；二期 M8 03-12 / M9 03-26 / M10 04-02；
- 阶段配色：P0 契约与设计 / P1 接入层地基 / P2 解析 / P3 索引 / P4 检索 / P5 会话与问答 / P6 联调 / P7 交付 / P8 质检内核 / P9 编排与计分 / P10 报告与验收；
- 工作表已冻结左侧信息列与表头（`H5`），横向滚动时任务名与日期始终可见；
- 节假日口径：一期 W9（元旦）容量 4 天；二期 W15（春节）容量 5 天但只排 3.5 人日。

依赖 `openpyxl`。本仓库已装于 `fastapi_admin_backend\backend\.venv`：

```bat
cd /d d:\workspace\ws_work\fastapi_admin_xian\service_brain_agent\00-document\02-服务大脑开发文档\scripts
d:\workspace\ws_work\fastapi_admin_xian\fastapi_admin_backend\backend\.venv\Scripts\python.exe gen_kb_plan_xlsx.py
d:\workspace\ws_work\fastapi_admin_xian\fastapi_admin_backend\backend\.venv\Scripts\python.exe gen_qc_plan_xlsx.py
```

写文件前会先做断言校验，任何一条不通过即中止：

| 脚本 | 校验项 |
| --- | --- |
| `gen_kb_plan_xlsx.py` | 任务数 36、人日合计 52.0、单人串行不重叠、任务不跨周 |
| `gen_qc_plan_xlsx.py` | 任务数 25、人日合计 44.5、需求追溯合计 44.5、单人串行不重叠、任务不跨周 |

改期只改脚本内 `TASKS` 的日期字段，同步修改对应的 `02-1` / `03-1` 任务表，避免三处口径漂移。
