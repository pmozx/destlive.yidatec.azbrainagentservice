# YD-AZ 服务大脑 AI 质检整体架构解决方案 — 概要

> 来源：`01-整体架构解决方案-原件.pdf`（YIDATEC，9 页扫描版演示文稿；原文件名「YD-AZ服务大脑AI质检整体架构解决方案.pdf」）

## 一、项目背景

该项目由 YIDATEC（亿达信息）为阿斯利康（AZ）IT 服务台设计，是一套整合 AI 与大语言模型（LLM）的智能质检整体解决方案。方案覆盖从单通质检、团队分析到改进闭环的完整链路。

## 二、整体架构

方案提出多层次架构体系，核心模块包括：

### 核心域模型

- **CallRecord（通话记录）** / **TranscriptSegment（转写文本段）** / **Recording（录音）**
- **KnowledgeArticle（知识条目）** / **Rule（规则）** / **Agent（坐席）**
- **Team（团队）** / **AuditLog（审计日志）**

### 处理流程

方案设计了一套完整的端到端处理管线：
1. **数据接入** — 录音文件、ASR 转写、工单数据、知识库
2. **预处理** — 说话人分离、静音检测、主题识别、意图识别
3. **AI 分析** — 规则引擎 + 大语言模型判定
4. **结果生成** — 单通报告、员工报告、团队报告、Findings 汇总
5. **输出** — 趋势看板、培训建议、知识库优化建议

## 三、关键能力模块

### 3.1 智能质检判定

结合传统规则引擎与大语言模型，实现：
- 硬性规则判定（开场白、身份核验、敏感词、静音检测等）
- 语义规则判定（服务态度、同理心、问题解决完整性）
- 知识一致性校验（坐席回答与知识库比对）
- 工单一致性校验（通话内容与工单记录比对）

### 3.2 知识库体系

- 支持按业务单元/业务域组织的层级知识结构
- 支持知识召回（RAG）用于质检比对
- 支持公共知识层、业务知识层、应用细节层的分层设计

### 3.3 Prompt 管理

- Prompt 模板管理
- 评估集管理
- 模型效果监控
- 人工反馈闭环与错误案例回灌

## 四、质检输出体系

- **单通质检结果** — 总分、维度分、缺陷标签、风险标签、证据片段
- **员工分析报告** — 周期趋势、高频缺陷、成长路径
- **团队/项目报告** — 缺陷分布、风险分布、知识点匹配度分析
- **Findings（管理发现）** — 问题描述、影响范围、根因判断、建议动作
- **趋势看板** — 覆盖率、合规率、CSAT 变化等

## 五、目标指标（部分示例）

- 质检覆盖率目标：> 90%
- 人工复核比例目标：< 10%
- 知识一致性准确率：> 80%
- 客户满意度（CSAT）：> 85%
- 团队合规率：> 70%
- 工单规范性：> 60%
- 一次性解决率（FCR）提升
