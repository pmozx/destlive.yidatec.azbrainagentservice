## 三、规范

- 命名遵循 [上级 README](../README.md) §二：`NN-<主题>-原件.<ext>` / `-概要.md` / `-详尽版.md`，同一编号共用主题名。
- **新增素材**：先补编号（顺延），再补概要/详尽版，最后在本表登记来源与版本；原件文件名保持 `NN-<主题>-原件.<ext>`，**原文件名写进「来源与版本」列**，不要塞回文件名。
- **原件更新**（如需求说明书升版）：替换原件并在本表「来源与版本」注明旧版与新版的差异日期，摘要同步修订；不得删行，历史以本表记录为准。
