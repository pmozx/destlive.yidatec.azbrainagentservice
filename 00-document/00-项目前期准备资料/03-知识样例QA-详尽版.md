**FAQ #1：如何下载安装企业微信 APP？**

**答案：**

1. 支持在官网或 app 端的应用市场下载企业微信。打开官网选择下载 iOS 版、Android 版的企业微信。
2. 扫码下载，见右侧二维码。

在手机下载安装了企业微信后，打开企业微信 app，需要输入手机号或微信号授权进行登录。（手机号指的是用户微信端绑定的手机号，如未绑定需要选择微信授权进行登录）

**升级所需信息：**
- PRID（K 账号）
- User Current Location（用户当前位置）
- User Contact Phone NO.（用户联系电话）

**更新日期**：2024-01-10

---

**FAQ #2：无法下载安装企业微信**

**答案：** 需注意手机版本：

1. **iOS（苹果）版**：需要 11.0 或更高以上的版本；iPhone5 不支持下载企业微信；目前只支持 64 位的设备，可与苹果客服确认当前使用的设备是否属于 64 位的设备。不支持下载设备下载企业微信会出现"无法下载 App，企业微信与此设备不兼容"的相关提醒。
2. **Android（安卓）版**：需要 Android 5.0 或以上，暂时不支持 Google Play 市场下载，若在 Google Play 市场下载企业微信会出现"您的装置与这个版本不相容"的相关提醒。
3. **兼容鸿蒙系统**，下载即可使用。
4. **暂不支持 Linux 系统**。

**升级所需信息：**
- PRID（K 账号）
- User Current Location（用户当前位置）
- User Contact Phone NO.（用户联系电话）
- 安卓手机型号
- 用户当前使用的手机操作系统版本
- 无法安装的现象描述
- 无法安装的手机报错截图或者用户操作的录屏

**更新日期**：2024-01-10

**FAQ #4：微信企业号：无法认证"阿斯利康"**

**答案：**

**1. 判断是否为新员工**

**(1)** 是且新入职 3 天内，无法进入企业号是正常的，从上游数据同步到企业微信后台需要 3 天左右的时间，建议用户等待数据同步后再关注即可；

**(2)** 是且入职超过 3 天，确认用户在关注的哪一步无法继续：
- 填写邮箱验证时遇到问题出现提示报错不存在于通讯录中，可派单至 AppSupport-CDC-CNAM-Wechat；
- 在接受验证码时有问题，解决方法参见第 6 条 FAQ：邮箱无法接收验证码；

**FAQ #6：微信企业号：认证过程中邮箱无法接收验证码**

**答案：**

1. 切换网络尝试；
2. 确认用户可否进入公司邮箱；
   - 如是，确认用户输入的邮箱信息是否正确，须在英文状态下输入，可多尝试几次；
   - 如否，需要等待，验证码接收时间较长，时间大概两三分钟之内即可收到。并且告知验证码验证时间是 15 分钟内有效。

**其他解决方法：**
- 验证码邮件被误判为垃圾邮件 → 进入垃圾箱，查找是否有"企业微信团队"发送的验证码邮件。
- 如 Outlook 邮箱中一直收不到验证码，可能是被拦截了，处理方式如下：
  1. 打开 https://astrazeneca.login-de.mimecast.com/m/portal/app/#/advanced/personal-on-hold ，使用 xxxxx@astrazeneca.com 邮箱进行登录
  2. 在 Personal On Hold 中查看验证码

### 1.4 群聊与消息（FAQ #10 ~ #11）

---

**FAQ #10：如何加入内外部群聊/如何邀请联系人加入群聊？**

**答案：**

1. 群内人员提供群聊二维码，通过扫码加入或是联系群内人员在群内点击添加成员，邀请自己加入群聊。获取群二维码：手机端群聊会话右上角"…"，点击群二维码名片。大于 200 人的群暂不支持扫码进群。
2. 后台无法操作统一创建内部群，需自行创建。操作方法请见附件。

**创建外部群的方法**：点击企微 APP → 消息 → 最下方"接收微信中的工作消息" → "前往微信选择群聊" → 勾选需要迁移的群 → 点击确定，然后点击回到企业微信，会出现提示"群聊已迁移"再点击确定。

**升级所需信息：**
- PRID（K 账号）
- User Current Location（用户当前位置）
- User Contact Phone NO.（用户联系电话）

**更新日期**：2024-01-10

**FAQ #11：用户无法收到应用的推送消息**

**答案：**

1. 指导用户查看"接收消息"状态，确保此选项为蓝色开启状态，步骤如下：
   - (1) 在企业微信中点击收不到消息的应用；
   - (2) 点击右上角"…"；
   - (3) 查看"设置"中的"接收消息"是否是蓝色打开的状态？如果是未打开状态，请用户打开此设置，之后即可收到推送信息。
2. 如果"接收消息"状态已是蓝色开启状态，仍无法收到推送消息，可派单至 L2 进行排查。

**升级所需信息：**

### 1.7 EA-Wecom 知识库特征分析

通过对以上 27 条 FAQ（编号 1~27，其中缺少 #20）的分析，可以总结出当前知识库的以下特征：

**知识条目结构特征**

| 要素 | 说明 |
|------|------|
| 编号体系 | 按应用内的问题出现顺序编号（1~27），非语义化的层级编号 |
| 组织方式 | 按应用（WECOM）为一级分类，不区分业务主题 |
| 问答粒度 | 一个问题一个条目，部分条目内容较为冗长（如 #16 验证问题、#6 验证码问题） |
| 升级标注 | 大部分条目标注了"Escalation Required"，部分以"否"标记（如 #14） |
| 版本管理 | 条目尾部标注更新日期（2024-01-10 ~ 2026-07-03），体现了生命周期管理 |
| Owner 机制 | 标注了 KB Owner（Kaili.Xiong）和 Assignment Group |

**对质检体系的知识库重组启示**

1. **当前问题**：FAQ 全部归在"WECOM (CHINA)"一个应用下，缺少业务主题维度（如"企业微信权限管理""企业微信认证""企业微信文件管理"等），不符合需求说明书中"按业务单元建设"的建议
2. **可行改造**：将现有 27 条 FAQ 按业务主题重新分类，如：
   - 企业微信 → 安装与下载（#1, #2, #3）
