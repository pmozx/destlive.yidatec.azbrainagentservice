## 四、口径提醒

1. **业务系统不动**：本项目是对既有服务大脑业务系统（GSI）做 AI Agent 赋能，业务事实与权限留在 GSI；
2. **技术路线**：LangChain + LangGraph 编排；对话模型走 AWS 上的 ChatGPT 类模型（Bedrock 托管的 OpenAI 系列）；向量化与重排序为私有化部署（bge-m3 / bge-reranker-v2-m3）；
3. **三条硬口径**：数字由 SQL 聚合产出、证据缺失即"未判定"、白名单下推而非结果后过滤；
4. **命名合规**：交付文档中自研中后台框架统一称「自研基座」，不出现存在商标或授权争议的第三方框架名称。
