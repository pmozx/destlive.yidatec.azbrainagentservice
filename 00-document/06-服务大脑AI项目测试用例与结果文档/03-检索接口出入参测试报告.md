| 环节 | 表 | 值 |
|------|-----|-----|
| 发布单元 | `sbp_km_doc_publication` | `id=0876a2b0-2788-4816-a1fd-7f26a2bfd061`，`doc_id=63858256ba974ede`，`record_id=9412b3a0-c617-4562-838a-ff2e6bc0bd34`，`team=AUD_SMOKE`，`index_status=succeeded` |
| 受众团队 | `sbp_sys_audience_team` | `id=1`，`group_code=AUD_SMOKE`（`group_name=App L3`、`audience_team=Smoke`），`status='1'`，`deleted=0` |

| 文档主记录 | `sbp_km_doc` | `knowledge_no=KB-0000039`，`status=Pending Owner Review`（不在 `Archived` / `Unpublished` 内，按 §四 仍可召回），`deleted=0` |
| 生效快照 | `sbp_km_doc_record` | `id=9412b3a0-c617-4562-838a-ff2e6bc0bd34`，`stage=audience`，`status=approved`，快照 `version=1`、`owner=kali04`、`expireAt=2026-11-30`、`invisibleTeams=[]` |
| 知识内容 | `sbp_ai_kb_publication` / `_revision` / `_chunk` | 由 `04_knowledge_search_prepare_entry.json` 经 03.1 写入，`revision=1`，3 条切片 |

授权链走向：`user_id=1` → `audience_team_member.team_id=1` → `audience_team.group_code=AUD_SMOKE` → `km_doc_publication.team=AUD_SMOKE` → 发布单元可检索。

> 铺场可重复执行：首次写库回 201；再次执行时 `request_id` 与正文都没变，幂等台账按原响应回放 201。改动铺场正文必须同步换 `request_id`，否则命中 `409 IDEMPOTENCY_CONFLICT`，后续检索用例会因无数据而全部 0 命中。

> 标识取自共享表而非自造：铺场请求的 `resource_id` / `record_id` / `knowledge_no` 按上表真实行填写（原为 `doc-lane2005-fdc` / `rec-search-001-v1` / `KB-HYDRO-2026-001`），因此命中结果的 `record_id`、`chunk_id`（`record_id:seq`）可直接回查 `sbp_km_doc_record`；`user_id` / `metadata.owner` 则统一按 user 1 取 `1` / `admin`（快照里 GSI 侧的 `owner=kali04` 只用于对账，不写进请求）。2026-11-05 已按上表重跑整套，`responses/` 与本节、§四的实测摘录均为真实标识。

## 二、接口契约与字段约束

### 2.1 请求正文

| 字段 | 类型 | 必需 | 约束 |
|------|------|------|------|
| `request_id` | string | 必填 | 本次操作 ID，原样回显 |
| `query` | string | 必填 | 查询词或自然语言问题，**不能为空或仅含空白** |
| `mode` | string | 必填 | 枚举 `keyword` / `natural_language`，其他值 400 |
| `limit` | integer | 必填 | 1–100，越界 400 |
| `tenant_id` | string | 必填 | 当前固定 `gsi-default`；检索结果按此过滤 |
| `user_id` | string | 必填 | GSI 用户稳定**数字主键**转字符串（非用户名） |
| `authorization` | object | 必填 | 短期授权块；缺块 400，跨度 >120s 400，已过期 401 |
| `authorization.scope_id` | string | 必填 | 授权追踪标识，非空 |
| `authorization.issued_at` | integer | 必填 | 签发时间，Unix 毫秒 |
| `authorization.expires_at` | integer | 必填 | 到期时间，Unix 毫秒；`expires_at > issued_at` 且跨度 ≤120 秒 |

### 2.2 响应正文（HTTP 200）

| 字段 | 类型 | 说明 |
|------|------|------|
| `request_id` | string | 原样回显 |
| `hits[]` | array | 命中列表，无证据时 `[]` |
| `hits[].resource_type` | string | `document` / `faq` |
| `hits[].resource_id` / `publication_id` / `record_id` / `version_id` / `revision` | — | 生效快照标识（`revision` 单调） |
| `hits[].knowledge_no` | string | 知识编号，仅展示 |
| `hits[].chunk_id` | string | 切片 ID，`record_id:seq` 规则确定性生成 |
| `hits[].title` / `hits[].snippet` | string | 标题与命中摘要（摘要只取本切片正文） |
| `hits[].page_from` / `page_to` | integer / null | 页码，从 1 开始 |
| `hits[].score` | number | 召回相关度 0–1，**不是回答正确率** |
| `returned_count` | integer | 必须等于 `hits.length` |
| `no_evidence` | boolean | `hits` 为空时 `true` |

### 2.3 拒绝顺序（谁先拦）

| 顺序 | 校验点 | 失败表现 |
|------|--------|----------|
| 1 | 签名鉴权（公共 5 头） | 401 `UNAUTHORIZED` |
| 2 | 正文 Schema（`query` 非空 / `mode` 枚举 / `limit` 范围 / `authorization` 必填） | 400 `INVALID_REQUEST` |
| 3 | `authorization` 时效（跨度 ≤120s、未过期） | 400 / 401 |
| 4 | `mode` 分发 → 授权链计算 → 召回 → 打分排序 | 200（空集合直接 200 + `no_evidence=true`；向量化不可用 500 / 授权不可用 503，都不是 `no_evidence`） |

> 授权数据不可用（共享表缺失/连接失败）时返回 503 `AUTHORIZATION_UNAVAILABLE`，**不降级为不校验授权的检索**。本期环境共享表可用，未触发该分支。

### 2.4 检索口径（`mode=keyword`）

| 环节 | 规则 |
|------|------|
| 切词 | 按空白与中英文标点切分，去重保序，**最多保留 8 个词** |
| 过滤 | 每个词在 `content` 或 `heading` 上做 ILIKE，**跨词 AND**（缺任一词即不入选） |
| 硬条件 | `tenant_id` 匹配 + `publication.status=active` + 当前生效 `record_id` + `revision.searchable` + `chunk.status=online` + `publication_id ∈ 授权集合` |
| 打分 | `score = 0.7×覆盖率 + 0.2×密度 + 0.1×标题命中`，保留 4 位小数，钳在 0–1 |
| 摘要 | 单条切片正文折叠空白后取定长窗口，命中点位于窗口前 1/4，截断处补「…」 |
| 排序 | `score` 降序 → 同分按 `publication_id`、`seq` 升序（稳定） |

### 7.3 运行期占位符

静态写死的时间戳一落地就过期，无法区分「跨度超限」与「已过期」，因此请求文件里用占位符，发送前换算：

| 占位符 | 换算规则 | 用途 |
|--------|----------|------|
| `__COMPUTED_AT_RUNTIME__` | 按 chunks 实算 SHA-256（`client.resolve_content_hash()` → `POST /v1/test/content-hash`） | 铺场 `content_hash` |
| `__AUTH_ISSUED_AT__` | 当前时刻 −5 秒 | 正常授权签发时间 |
| `__AUTH_EXPIRES_120S__` | 当前时刻 +115 秒 | 正常授权到期（跨度 120 秒） |
| `__AUTH_EXPIRES_300S__` | 当前时刻 +295 秒 | 跨度超限用例（跨度 300 秒） |
| `__AUTH_EXPIRED_ISSUED__` | 当前时刻 −60 秒 | 过期用例签发时间 |
| `__AUTH_EXPIRED_EXPIRES__` | 当前时刻 −30 秒 | 过期用例到期时间 |

换算实现只有一份：`backend/tests/contract/case_data.py` 的 `resolve_authorization()`。
