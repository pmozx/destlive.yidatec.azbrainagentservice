## 二、口径与边界

| 项 | 说明 |
| --- | --- |
| 契约版本 | v2.1.0（`info.version`），20 个接口 / 18 个路径，编号 #01–#20 |
| 认证 | HMAC-SHA256 四头签名（`X-AI-Client` / `X-AI-Timestamp` / `X-AI-Nonce` / `X-AI-Signature`）；具体实现见 `backend/app/core/security_signature.py` 与规范 `03-…/01-团队开发规范.md` §2 |
| 数据位置 | 与 GSI 共用 `service_brain` 库、`public` schema；AI 侧表以 `sbp_ai_` 前缀区分，切片与向量在独立 schema |
| 手册效力 | 手册定义**对接契约**，不作为服务上线或验收证明；示例中的域名、ID、时间、摘要不可用于生产 |
| 只读的例外 | 仅当 GSI 发布新版手册/DDL 时整份替换，并在本节记录替换日期；不在原文件上做局部批注 |
