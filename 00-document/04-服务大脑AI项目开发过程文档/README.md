## 三、归档规则

| 规则 | 说明 |
| --- | --- |
| 阶段产物建子目录 | 新阶段（如 P2 解析接口、P3 知识写入）完成后建 `NN-<阶段名>/`，目录内 `01-` 起连续编号；不把阶段文档平铺到本目录根 |
| 证据文件不可改写 | 由脚本生成的文件（如 `verify_m1 --record` 产出的验收记录）重跑时**另存新文件**并在同目录 README 登记，不覆盖历史证据 |
| 周报只追加 | `04-项目周报.md` 新的一周写在文末；事后更正写成「补充（日期）：…」，不覆盖原句 |
| 评审报告带版本 | 代码评审报告的每轮结论写在文首「变更记录」，正文用【vX 复核】标注已失效条目，避免读者按旧结论动手 |
| 结论必须可复跑 | 每条验证结论注明复跑命令与运行日期；无复跑方式的结论视为待证 |
