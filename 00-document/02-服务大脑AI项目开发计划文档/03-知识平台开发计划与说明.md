## 一、本文件说明什么

本文只回答三个问题：

1. **这一期到底交付什么**——20 个接口（#01–#20）+ 7 项跨切面能力，不含前端页面，不含语音质检；
2. **怎么排、谁来做**——**POC 先行**：P0（W1–W2）先用最小实现验证 #01→#03→#07→#14 链路与签名冒烟，再进入正式开发；单人串行，17 个自然周（W15 为春节假期周）/ 78 个工作日 / 36 个任务 / 63.5 人日，M0–M8 九个门禁；
3. **工程口径是什么**——/v1 审计纳入、sbp_ai_ 表命名、实时权限下推、ChatGPT 5.6 模型栈（§七）。

工时为什么从上一版 58.5 人日调整为 63.5 人日（+6.0 POC、−1.0 复核闭环）、v1.8 与 v2.1 差在哪，见 `02-接口交付范围与工时评估.md`，本文不再重复。

## 二、交付范围

### 2.2 跨切面能力（不单列接口，但必须交付）

| 编号 | 能力 | 落在 |
| --- | --- | --- |
| C1 | HMAC 四头签名鉴权（`X-AI-Client/Timestamp/Nonce/Signature`，`authorization.expires_at≤120s`，±5 分钟窗口）+ nonce 防重放 | T0.1（POC 冒烟）→ T1.1（生产化） |
| C2 | 统一错误体 `{error:{code,message,retryable}}` 与全量错误码 | T1.2 |
| C3 | 三类幂等台账（`job_id` / `event_id` / `request_id`），同 ID 异正文返回 409；超时结果由 `sbp_ai_system_request_log` 承接 | T1.3 |
| C4 | **对接接口统一审计**：20 个 `/v1` 接口纳入 `sbp_ai_system_api_log`，扩展 `auth_mode`/`client_id`/`request_id`/`security_check(JSONB)`，被拒请求留痕、签名只存摘要、nonce 全量留存 | T1.4 |
| C5 | 20 路由骨架与契约冒烟（独立 `/v1` router：不挂 Bearer，**纳入审计中间件**） | T1.5 |
| C6 | 实时权限计算与 SQL 下推：只读 8 张 GSI 共享表，越权 0 命中，不可用 503 | T4.3 |
| C7 | 共库治理：public schema + `sbp_ai_` 前缀（23 张表）+ 启动期 bootstrap 幂等建表 | T1.0 |

### 2.3 明确不包含

前端页面（知识中心 UI）、点赞点踩、权限计算（GSI 维护）、审批发布流、种子文档入库、UAT 组织与培训；**契约复核闭环**（暂缓，遗留问题在 POC/联调期消化，见 02-01 暂缓说明）；**语音质检全部内容**（接口文档未提供，暂缓）。若追加前端，需在本计划外增加 12–15 人日。

## 七、工程约定（v2.1 口径，与 v1.8 的关键反转）

1. **`/v1` 纳入审计**：独立 `/v1` router 不挂 JWT Bearer，但**必须经过审计中间件**（调整方法白名单与 `API_LOG_SKIP_PATHS`）；20 个接口全量落 `sbp_ai_system_api_log`，安全头校验结果落 `security_check` JSONB，被拒请求同样留痕，签名只存摘要、nonce 全量留存（ADR-13 / FR-AUD）。
2. **表命名**：AI 表一律 `sbp_ai_[模块名]_[业务名]`，模块码 `system` / `kb` / `voice`（**不再设 `integration` 过渡域**，2026-11-02 撤销）；与 GSI 共用 `service_brain` 库 public schema；公共字段走 ModelMixin（`id` int8 / `uuid` / `created_time` / `updated_time`，无软删字段）；AI 侧启动期 bootstrap 幂等建表（无迁移工具），与 Flyway（GSI）分治，CI 互检（ADR-10）。
3. **权限方案**：检索期实时只读 8 张 GSI 共享表并 SQL 下推（`sbp_sys_org`、`sbp_sys_org_member`、`sbp_sys_audience_team`、`sbp_sys_audience_team_member`、`sbp_sys_user`、`sbp_km_doc`、`sbp_km_doc_publication`、`sbp_km_doc_record`）；**禁止降级全库检索**；共享表不可用返回 503 `AUTHORIZATION_UNAVAILABLE`（ADR-8）。ID 对齐：`user_id` int8、`publication_id`/`record_id` varchar64。
4. **模型栈**：生成 ChatGPT 5.6（OpenAI 兼容端点，`LLM_BASE_URL`/`LLM_MODEL` 配置化）；向量化 bge-m3（1024 维，`VECTOR_DIM=1024`）；精排 bge-reranker-v2-m3；索引 pgvector HNSW 余弦；编排 langchain 1.3.9 + langgraph 1.2。
5. **失败语义**：解析任务失败走 HTTP 200 + `error_code`/`error_message`（任务失败 ≠ 请求失败）；请求级失败走 4xx/5xx + 统一错误体。
6. **幂等口径**：同 ID + 完全相同正文 → 幂等返回原回执；同 ID 不同正文 → 409；删除类保留幂等墓碑。
7. **POC 口径**：POC（T0.1–T0.4）以自签测试密钥、临时表结构、mock/配置化端点做最小验证，产物定位为验证骨架；正式实现自 T1.x 起按生产标准重做，POC 结论与契约疑点清单是正式开发与联调的输入。
