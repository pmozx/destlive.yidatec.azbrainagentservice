## 二、交付范围与边界

### 2.1 交付面

- **21 个 `/v1/*` 接口**（19 个路径）+ 跨切面能力 C1–C7（签名、防重放、幂等台账、统一错误体、实时权限下推、审计、共库治理）；
- 全部由 GSI 后端签名调用，AI 返回裸 JSON；**不含**浏览器直连；
- 23 张 `sbp_ai_` 表与启动期 bootstrap 幂等建表。

### 2.2 明确不在本次范围

| 项 | 说明 |
| --- | --- |
| **POC 验证阶段** | 本次不设 P0；不产出 POC 骨架、POC 结论报告与契约疑点清单（疑点直接在联调期 T7.3 闭环） |
| **前端页面与交互** | 知识中心 UI、座席页、管理台页面均不含；原「追加前端 12–15 人日」不进入本计划 |
| **管理端维护接口** | `/api/v1/kb/*` 系列不在 21 接口交付面内（与 `02` §2.3、`03` §2.3 口径一致）；如需交付须另行评估 |
| **语音质检** | 接口手册未提供，范围无法冻结；`voice` 域 8 张表仍在建表基线内（T1.0） |
| **契约复核闭环** | 逐项复核不作为前置阻塞，疑点在联调期消化（T7.3） |
| **GSI 侧职责** | 权限计算本身、审批发布流、点赞点踩、种子文档入库运营、UAT 组织与培训 |

### 2.3 工程口径（关键反转，沿用 v3 契约与 `02`/`03`）

1. **`/v1` 纳入审计**：独立 router 不挂 Bearer，但必须经审计中间件；被拒请求同样留痕，签名只存摘要、nonce 全量留存；
2. **表命名与共库**：`sbp_ai_[模块名]_[业务名]`（模块码 `system`/`kb`/`voice`），与 GSI 共用 `service_brain` public schema，启动期 bootstrap 幂等建表；
3. **权限**：检索期实时只读 8 张 GSI 共享表并 SQL 下推，**禁止降级全库检索**，不可用 503 `AUTHORIZATION_UNAVAILABLE`；
4. **模型栈**：生成 ChatGPT 5.6（OpenAI 兼容端点，配置化）、向量化 bge-m3（1024 维）、精排 bge-reranker-v2-m3、索引 pgvector HNSW；
5. **失败语义**：解析任务失败走 HTTP 200 + `error_code`（任务失败 ≠ 请求失败）；请求级失败走 4xx/5xx + 统一错误体；
6. **幂等**：同 ID 同正文 → 回放原回执；同 ID 异正文 → 409；删除类留幂等墓碑；
7. **跨切面编号统一**：采用 `02` §2.2 口径 **C1 签名 / C2 防重放 / C3 幂等 / C4 错误体 / C5 权限下推 / C6 审计 / C7 共库**（`03` §2.2 的旧编号在本文不再引用，避免同一编号指代不同能力）。
