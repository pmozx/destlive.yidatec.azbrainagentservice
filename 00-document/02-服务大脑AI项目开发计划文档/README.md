## 五、重新生成 Excel

依赖 `openpyxl`（`backend\.venv` 已装 3.1.5；换环境先执行 `backend\.venv\Scripts\python.exe -m pip install openpyxl`）：

```bat
cd /d d:\workspace\ws_work\fastapi_admin_xian\service_brain_agent\00-document\02-服务大脑AI项目开发计划文档\scripts
d:\workspace\ws_work\fastapi_admin_xian\service_brain_agent\backend\.venv\Scripts\python.exe gen_kb_plan_xlsx.py
d:\workspace\ws_work\fastapi_admin_xian\service_brain_agent\backend\.venv\Scripts\python.exe gen_kb_iface_xlsx.py
```

写文件前会先做断言校验，任何一条不通过即中止：

| 脚本 | 校验项 |
| --- | --- |
| `gen_kb_plan_xlsx.py` | 任务数 36、人日合计 63.5、工作日不重叠 |
| `gen_kb_iface_xlsx.py` | 任务数 32、人日合计 50.5、接口 21 个 / 32.0 人日、接口拆分与任务人日逐条相等、跨切面 18.5、工作日不重叠、里程碑 8 个均落周 |

改期只改脚本内 `TASKS` 的日期字段，并同步修改 `03` §六（基线）或 `05` §七（v2 口径）任务表，避免两处口径漂移。
> `06` 由 `INTERFACES`（21 行）与 `TASKS_RAW`（32 行）同源生成：新增接口必须同时登记接口行与任务行，否则断言失败。
